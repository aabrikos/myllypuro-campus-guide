# Myllypuro Campus Guide
An AI-assisted indoor navigation prototype for the Vibe Coding assignment. A student selects a first-floor destination and follows a centered arrow on their phone. [Open the live guide](https://myllypuro-campus-guide.garden-lotus-4017.chatgpt.site).
## Try it
Open index.html in a desktop browser. Select **Demo classroom**, then **Practice walk**. Hold the turn and walk buttons, or use the left, right and up arrow keys. Exit returns to the directory. The site runs without an installation or build step.
On an iPhone, open the live HTTPS link in Safari. Start beside the info stand at the blue dot, facing toward the dining area as drawn. Choose a destination, tap **Start camera**, allow camera and motion access, and hold the phone upright. The route begins at that assumed position. Website hosting requires serving this folder over HTTPS.

## Scope and evidence
The guide offers 51 plan-based routes. Doors, access and distances are estimates based on a drawing dated 1 December 2015. All 51 destination controls and simulated arrival states were exercised in a browser. That test does not establish real-world positioning accuracy. The Showroom route ends near reception.
